# Museboard 图片采集助手安装说明

## 安装

1. 打开 Chrome 或 Edge 浏览器。
2. 进入扩展页面：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择本文件夹：`browser-extension`。
6. 如果之前装过旧版，请先删除旧版，重新加载本文件夹。

## 批量采集

1. 先保持 Museboard 本地网页运行：`http://127.0.0.1:3000`
2. 在 Museboard 里点击 Pinterest / Amazon / 花瓣 / Instagram 的「打开并采集」。
3. 在目标网站页面点击浏览器右上角 Museboard 插件。
4. 点击「开始批量选择」。
5. 连续点击页面上想采集的多张图片。
6. 图片会出现绿色描边，表示已选中；再次点击可取消。
7. 选完后点击右下角「完成采集」。
8. 回到 Museboard，图片会自动显示到下方，并保留来源页面链接。

## 注意

- 仅采集你有权保存或仅用于灵感参考的图片。
- 商用前需要确认版权或重新制作原创图片。
- 不支持绕过登录、验证码、反爬或禁止下载限制。
